# 决策

## 2026-10-11：共享原 Rust 核心，原生 Mac 容器

保留 Windows v0.1.4 的额度解析、Provider、Monitor、Worker、Config 和圆窗绘制。Rust 通过只在 AppKit 主线程调用的 C ABI 暴露快照、配置、刷新和 Retina BGRA；Swift AppKit 管理原生窗口、控件与系统集成。选择静态链接避免另一个常驻桥接进程和 IPC 状态副本。Windows 模块与依赖按 target 隔离。

## 2026-10-11：平台适配保持原设计

常规 / 关于的白底、绿橙配色、布局、圆角、数据顺序、图标原图与 132 pt 圆窗保留。使用 Mac 系统字体和 SF Symbols；菜单栏替代托盘；点击 / 双击菜单栏图标打开主界面，右键打开原有五项菜单。登录启动使用 SMAppService，默认关闭，注册仅由用户开关触发；不创建 LaunchAgent。

## 2026-10-11：独立本地项目，明确发行边界

本地 checkout 为 NanfengCodexQuota-Mac，windows-source remote 仅作来源，未创建或推送远端 Mac 仓库。交付 universal .app 和 DMG；本地 ad-hoc 是运行封装，Developer ID / Apple 公证需完整 App 专属外部配置。macOS 13+ 为最低系统版本；Intel 交叉构建不等于 Intel 真机验收。

## 2026-10-11：限定圆窗配色与紧凑玻璃菜单

圆窗以首个 Mac 版本的几何为基线：132 pt 画布、51 pt 环半径、原环宽、字重、数字和更新时间位置保持不变。只参考用户旧版截图调整白色主字、深色背景和明亮红橙黄配色，并将背景扩展到细环下方以填实透底缝隙。后台查询保留上次成功时间，成功后直接更新，不显示刷新中；失败与过期仍如实显示。

右键弹窗保持原五项动作，采用透明度适中的原生浅色玻璃。macOS 26 使用 regular NSGlassEffectView，旧系统使用菜单磨砂材质。固定 190×166 pt、13 pt 字号、14 pt 图标与 28 pt 行高，所有菜单项完整呈现；固定在点击点右上方 8 pt，仅在屏幕边界作必要避让，刷新及悬停不重排。没有额外折射动效或强烈彩色高亮。

## 2026-10-11：运行中程序替换导致身份失效的修复

用户开启登录启动时出现 Operation not permitted。旧进程在磁盘可执行文件被原地重建后，SecCodeCopyGuestWithAttributes 返回 errSecCSBadObjectFormat (-67049)，对照当前宿主返回有效身份。修复为构建前和替换前阻止运行中的精确目标，并用新文件原子替换二进制。退出旧实例、重启后签名身份校验返回 0，实际开启登录启动成功。保留用户已启用的登录项；本轮不注销或更换签名身份。

弹窗禁止自绘黑色硬描边，保留系统常规玻璃及轻柔边缘，不叠加强烈折射或染色。

## 2026-10-11：只修菜单的双层边缘，保留阴影

用户截图中的外层矩形硬边来自开启的窗口级阴影，与圆角玻璃表面叠加。关闭窗口级阴影；透明宿主只绘制圆角轮廓外的阴影，中心清空，不增加底色、描边或第二层材质。16 pt 透明空间容纳 10 pt 模糊、2 pt 下偏移和 0.16 透明度的阴影，使其自然消退。玻璃仍为原 regular 材质与 0.08 白色 tint；可见表面固定 190×166 pt，点击右上 8 pt、菜单内容和字体不变。QA 按实际玻璃表面检查锚点，允许系统至多一个物理像素的坐标对齐。

## 2026-10-11：按最新反馈将进度环只向外加宽

用户明确要求彩色环向外拓宽，并消除底部暗底像黑边的效果。这覆盖此前只调颜色、不改细环的本项目限制：内侧抗锯齿边界保持半径 47.4 pt，外侧从 54.6 扩至 57.6 pt，色环和消耗轨道共用几何，起点圆帽及进度端点同步居中。暗底只覆盖内缘的无缝交叠区域，不再伸到彩色外沿。132 pt 画布、文字位置/字重、配色、更新时间与菜单全部保持。像素回归检查确认新底部环带为不透明橙色，环外仅为透明阴影，内侧无重新出现的透底缝隙。
